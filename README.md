# security-agent-toolkit

네트워크·보안 과정 수업 실습 저장소입니다. 과목별로 폴더를 나눴습니다.

| 폴더 | 과목 | 기간 | 내용 |
|---|---|---|---|
| `agent_core/` | 1과목 · 파이썬 보안 자동화 | 2026-09-22 ~ 10-08 | 변수·조건문·함수, 예외·로깅, JSON, 정규식 탐지 룰, API·웹훅, LLM 요약, 보고서 파이프라인 |
| `network_zt/` | 2과목 · 네트워크 · Zero Trust | 2026-10-12 ~ 10-20 | OSI·TCP, IP·서브넷, DNS, VPN·방화벽, 클라우드, Zero Trust, Docker |
| `access_control/` | 3과목 · 접근통제 | 2026-10-21 ~ | RBAC, 예외 정책, 권한 요청·SLA, 접근 점검, 과다권한 리포트 |
| `docs/` | 날짜별 공부 기록 | 2026-10-06 ~ 10-16 | 그날 새로 쓴 명령, 찾아본 것, 막힌 것 |
| `_확인필요/` | 정리 대기 | - | 수업과 관련이 확실하지 않은 파일. 확인 후 지우거나 되돌림 |

- 노트북 파일 이름은 `YYMMDD_오전/오후_주제.ipynb` 형식입니다.
- `.env`, `.venv` 는 올리지 않습니다(`.gitignore`).
