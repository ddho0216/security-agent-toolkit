# 2026-10-08 (목)

## 오늘 새로 쓴 명령
git config, git add, git commit, git push


## 찾아보고 알게 된 것
add 와 commit 과 push 는 
`add`는 커밋할 파일을 준비하고,
`commit`은 변경 내용을 기록하고,
`push`는 그 기록을 GitHub에 올리는 과정이다.

untracked · tracked · staged 는  
`untracked`는 Git이 아직 관리하지 않는 파일,
`tracked`는 Git이 관리 중인 파일,
`staged`는 다음 commit에 포함될 준비가 된 파일이다.

## 막힌 것
`git push`를 했는데 새 파일이 GitHub에 올라가지 않았다.
확인해보니 새 파일이 untracked 상태였고,
`git add`와 `git commit`을 하지 않은 상태였다.
