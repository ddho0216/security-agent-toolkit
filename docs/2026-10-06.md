## 찾아보고 알게 된 것
API 키는 서비스가 요청의 사용 권한과 사용량을 확인하는 데 쓰는 정보이다.
LLM은 질문이나 지시를 입력받아 답변이나 요약 같은 글을 만들어 주는 AI이다.
무료 등급은 비용 없이 정해진 사용량과 기능 범위 안에서 이용하는 단계이다.
보안 담당자가 관리하는 서버에는 리눅스·유닉스 계열이 널리 쓰인다.
깃배시를 쓰면 윈도우에서도 리눅스 서버와 비슷한 명령을 연습할 수 있다.
