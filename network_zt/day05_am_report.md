## 4교시 · 구역 규칙 코드

### 문제 4-1 · 규칙 판정 코드 읽고 설명하기

- (가) 함수 `default_policy` · `match_rule` · `judge` 가 각각 무엇을 하는지 적어 주세요.
  - 쓸 내용: 「default_policy: … / match_rule: … / judge: …」 함수마다 자유롭게
  - 답: 
default_policy - 규칙에 맞는 것이 없을 때의 기본 정책을 알려 준다. 같은 구역, 내부망 출발, 인터넷으로 나감은 허용하고, 나머지는 차단한다 
match_rule - 규칙 하나가 요청과 맞는지 출발, 도착, 포트를 비교해서 True, False를 알려준다 
judge - 요청 하나를 규칙표 위에서부터 판정해서 동작과 규칙 번호를 리턴한다 

- (나) `judge` 가 리턴하는 값 두 개는 무엇이고, 어느 줄이 만드나요?
  - 쓸 내용: 「값 ①: … / 값 ②: … / 만드는 줄: …」
  - 답: 
permit, deny
규칙 적용시 rule[4], rule[0], 규칙 미적용시 default_policy(src, dst)

- (다) 🔍 `judge` 의 `for` 는 맞는 규칙을 찾으면 바로 `return` 합니다. 같은 요청에 규칙이 둘 이상 맞는다면 어느 규칙이 적용되나요? 왜 `return` 으로 바로 끝내도록 만들었나요?
  - 쓸 내용: ① 규칙이 둘 이상 맞을 때 적용되는 규칙 ② 방화벽이 「첫 번째로 맞는 규칙」을 쓴다는 점과 이어서 `return` 으로 바로 끝내는 이유
  - 답:
+클로드 답 : 1 위에 있는 규칙이 적용된다. for가 규칙을 위에서부터 보다가 처음 맞는 규칙에서 return하고 함수가 거기서 끝나기 때문이다. 
2 방화벽은 첫 번째로 맞는 규칙을 쓰므로 찾자마자 끝내도록 했다 return 으로 끝내지 않고 끝까지 돌면 아래 규칙이 위 규칙의 결과를 덮을 수 있습니다.
